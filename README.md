# Outpost
A self-hosted dashboard platform for weather, alerts, sensors, power monitoring, and telemetry. 

## Weather Providers
- Open-Meeo (openmeteo)
- Pirate Weather (pirateweather)
- MET Norway (metno)
- OpenWeatherMap (openweathermap)

### Recommended default
```env
OUTPOST_SOURCE=openmeteo
```
