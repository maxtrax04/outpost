# Fonts
Place optional local font files here.

Recommended free(ish) options:

- **Monofonto**
   - Suggested filename: `monofonto.ttf`

- **Share Tech Mono**
   - Suggested filename: `share-tech-mono.ttf`

- **Oxanium**
   - Suggested filename `oxamium.ttf`


> If `monofonto.ttf` is present, the dashboard will use it.
> 
> If not, the CSS will fall back to monospace fonts.
