# Outpost

A self-hosted, themeable weather dashboard for wall displays and phones: current conditions, the
forecast, official alerts, and an optional map with rain radar, in themes from green-phosphor
terminals to black on white for ePaper.

The add-on shows Outpost in Home Assistant's sidebar and uses Home Assistant's home location, time
zone, and units unless you set others. A wall tablet can also open it on its own port.

This add-on is experimental. See the Documentation tab, and the project at
https://github.com/maxtrax04/outpost.
